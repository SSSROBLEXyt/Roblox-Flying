# Roblox-Flying
This allows you to fly in any Roblox game.

Disclaimer: Use this project at your own risk. The author is not responsible for any account bans or other consequences resulting from using these scripts.

Note: This project and its scripts are only supported when executed with Delta.

## Usage

1. Open your preferred Roblox executor that supports Delta.
2. Place the `src` folder's Lua files where your executor expects them (or load `src/main.lua`).
3. Run or inject the script inside a Roblox client session. The UI will appear in PlayerGui.

## Publishing this repository

If you want to make this repository public on GitHub, the simplest steps are:

